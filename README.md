# Ratio_Regression_Simulations
The GitHub page contains reproducible R code. 
1. You will install the necessary packages to access the diamonds dataset, which has 53940 observations.
2. Run the code to obtain a reduced dataset with 10000 observations using Simple Random Sampling Without Replacement.
3. Run the code to visualise the boxplots as well as a plot of carat weight vs diamond price to observe the linear correlation between the two variables.
4. Run the code to determine an optimal sample size required for the survey using Neyman allocation.
5. Run the code to create a survey design object, which will be used for further analysis.
6. Run the code to obtain the results for the survey design object, plots, and Monte Carlo estimates.

7. The GitHub page contains the diamond_finite dataset, which has a finite population of 10000 observations. The stratified_final dataset has a sample of 1253 observations, where the cut variable is the stratum.
